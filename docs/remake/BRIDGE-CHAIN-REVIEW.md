# 跨線橋の探索と道具連鎖（2026-09-30）

対象は KISEN/remake の Q09→Q14→Q13 と、橋の方位を示す三視点。計画書03/04/07を参照。作者既知の操作検査であり、初見の難度や核心K3の合格ではない。

南ホーム西端に実在する階段を設け、跨線橋から駅舎の北壁・西端、東への線路、北の保守柵をそれぞれ見る。最初の橋写真0099800fは南側の入口・時計を橋から見せてしまい、暗さも不足したため採用しなかった。現在の橋屋根写真0e4265e1は配置ガイドに合う。東向き画像の初稿fc938d80には北ホームに余計な駅舎が現れたため、裸のホームへ修正した860632e4を採用。南ホーム駅舎側の東端には二つ目の橋に見える階段があったため、e220cc07で駅舎・時計・扉を維持して右端を終端の柵へ変更。西の階段から橋へ往復する通常操作とPC目視を確認。

Q09は駅務室北側の傘立てに固定された鉤付き棒。輪を傾けてから棒を持ち上げる。正面から引くと幅が合わず、状態は進まない。全景の棒・輪、輪の角度、取得後の空の輪と持ち物の棒を各別写真で表す。Q14は橋の広い手すり面から接写へ入る。上側では支柱に当たり、鉤付き棒を選び下の隙間へ差す→奥へ送る→先を返す→札を引き寄せる。途中で戻してやり直せ、途中の棒と札は全景・接写で同じ所在になる。札を取ったあとの短い針金は手すりに残る。薄い片は実際の品として持ち物へ入る。

Q13は支えを起こし、薄い片を選択してばね付き横棒を押してから柵を開ける。薄い片を使わず柵を開けられた初稿は計画の Q14→Q13 を失わせたため修正。柵は右の蝶番で開く。左柱には空の受け口が残り、開いた柵の先端とばね・支えは右に移る。開いた後の接写でばねが左柱に浮いて残る画像と、二写真合成の水平継ぎ目は不採用。支えは開いた柵から個別に外して持ち物へ入る。閉じた柵へ支えを戻すと再操作できる。Q16の灯具固定への再使用はまだ未実装。

PCでは駅務室の輪の失敗→傾け→取得、橋の上からの失敗→下の隙間→到達→回転→回収、柵で薄い片を選ばない失敗→選んで開放→北ホーム、支えの取外し→閉扉→再設置を操作。390×844タッチで駅務室→待合室→ホーム→橋→札→柵→北ホームを操作。最初のタッチでは視点矢印が駅務室の出口と重なって停止し、矢印を写真上側へ移して再実行した。最終のタッチ結果は north、pin/hook inventory、gateOpen=1、ページ横はみ出しなし。モデルは支え・棒・札・柵の途中と保存不整合をテストした。

採用一覧は docs/remake/assets.json と生成呼出 docs/remake/prompts/imagegen-calls.json を参照。根拠画像は verification/2026-09-30-bridge。採用外の候補は生成領域に残し、本番ディレクトリへは置いていない。bridge/east-tracks は先行した素の線路写真としてまだ採用一覧にあり、画面では札のある状態を使用している。最終整理時に参照と不要素材を照合する。
