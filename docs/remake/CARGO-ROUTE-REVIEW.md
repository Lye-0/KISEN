# 荷物室→地下窓→北ホーム：モデル切替前のチェックポイント

## 今回実装した現物

- 駅務室の右戸から荷物室へ入り、長箱・幅箱・台車・棚をそれぞれ床の溝に沿って移動できる。衝突と可動域は `cargo.ts` の21状態モデルで判定し、既知の手順以外も合法なら受け付ける。ドラッグか荷の選択後の方向ボタンで操作。保存・再開で配置を保持。
- 棚が階段戸の前にある間は戸を見せず、棚を退けると実物の閉じた木戸が現れる。開くと写真が開扉状態に替わり、地下へ通れる。地下には高架脚と、その下を続く地上線を見る独立の窓写真がある。
- 地下から北ホームの蓋を押し開ける。北ホーム側も閉／開の現物写真に切替。閉じた蓋を外側から先取りできない。開いた蓋と開いた荷物室戸を通って往復できる。帰路の通行可能な扉は開状態で描画する。
- PCと390pxタッチで、荷物の6操作→棚の退避→木戸開放→地下窓→北蓋開放→北ホーム→地下→荷物室の導線を実画面で操作。390pxの荷物室は元写真を640px幅まで表示するが、元素材1672pxより小さく、拡大の画質劣化はない。戻り操作を写真の下へ置く。
- PCの地下窓・北ホーム開閉、北蓋閉時のブロックを目視。検証画像は `verification/2026-09-30-cargo/`。

## 正本との照合と残る不合格

- Q15の「南外壁六間と既知室五間の対応」を、室内窓・外壁・棚の実写真だけで初見の人が推理できるかは未検証。棚の操作自体が先に発見可能であり、外形推理を必須ゲートにしていない点は計画どおり。
- **重要：荷物室写真の投影校正カメラは現時点で駅舎南壁の外側に相当する。** `CargoRoom.tsx` に暫定の校正値として隔離した。`geometry.ts` の正本建物カメラへ混ぜてG1合格と扱わない。次のモデルは駅務室から荷物室へ入る実位置・南北窓・外壁の位置・荷の投影を一つの共有空間で再点検し、必要なら荷物室の採用写真とスプライトを作り直す。これはYOTSUZURI/KISENで繰り返してはいけない空間不整合の可能性。
- Q25は橋・地下窓・北ホームの三地点で同じ高架と地上線を見られる段階。ただし写真ごとの手前の駅舎や線路本数が完全一致するか、E–Fの屋根下の連続・C–X終端を誤読なく確定できるかは未合格。北ホームの新しい全景は390pxでは小さいが、地下窓の専用観察写真は元画素以下の縮小で読める。
- Q27の可動レバーと線路差分、Q16の支え・灯具再使用、Q20の四つの券実例は未実装。全体は代表制作中で、G1/G2/G3は未合格。通常URL `/` もまだ旧版。今回の縦導線を完成品と報告しない。
