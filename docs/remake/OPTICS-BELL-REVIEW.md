# 灯具の窓照射・応答ベルの実装点検（2026-10-01）

Q16/Q23の操作を通常探索の灯具小屋へ接続した。保管側から西の窓へ向きを変え、持ち物の灯具または交換灯具を受け口に置く。橋の柵から回収した支えを灯具の下へ取り付けられる。支えの交換には灯具を一度外す。持ち物を複製せず、全操作は可逆。

光源は [21.4,-3.2,z]、裸の受け口 z=1.0、支え付き z=1.4。西窓 x=20、台0.9、上端2.05と格子、低壁 y=-1.5 高さ1.1、手前庇1.75..1.95、奥庇 y=.2 高さ1.8..1.9を同じレイ判定で扱う。光軸は上下左右0.5度刻み、円錐半角1.8度。E–F中点へ向けた裸の灯具は壁に当たり、支え付きは抜ける。上へ向けると庇に当たる。

拡大した外景は同一写真の暗い下地と照射用の明るい層を重ねる。地面、壁、庇、標柱をワールド座標で分割して光のマスクを投影する。写真の二本の標柱は初稿で座標とずれていたため除去し、透明部品から同じカメラで描くよう改めた。高さ2.1、幅0.4、白はz=1.4の一溝、黒はz=1.05/1.4の二溝。明るさで景色の位置は動かない。窓景・記録内の外景は元画像の解像度を上限に拡大する。

ベルの二接点は、Ⅰが900ms後と1450ms後の固定列、Ⅱが各入力の900ms後の返答。正解の固定リズムや観察済みフラグは置かない。任意の時刻列を最大32打まで入力し、紙送りで試行をやり直す。紙の二列と灯で音無しでも比較できる。記録には保存時点までに返った時刻のみ残す。音はbellCircuit.tsの決定的な金属音合成で、返答の描画と同じ時刻を使う。返答音の再生担当はBellAudio一箇所。画面側の短いアニメーションはローカル状態のみを更新し、セーブデータを毎フレーム更新しない。

窓から見える応答灯と北ホームの灯を共通の位置 [5,8,1.3] として扱う。Ⅱへの接続が停車灯の給電条件になる。列車の停止は現回線・現路線・現在の灯具位置・現在の遮光板を再評価する。旧セーブで既に停車灯を取り付けた状態は現回線へ移行し、既存の停車試作はその条件を最初から持つ。

採用素材は assets.json と prepare-remake-assets.mjs に登録。field/windowは標柱除去済み背景、field-postsは1312×1199の透明二部品、lamp-rearは背面、bellは固定ハンドルを除去済みの盤、response-beaconは971×1619透明部品。新しい輪郭を補うために写真を描き足す処理はしていない。native SVGは可動部品、光、紙の線、標柱の溝に使用。
