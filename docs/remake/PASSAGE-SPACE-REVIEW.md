# 地下横断通路の距離と高さ

荷物室と北ホームを数段の階段で直結する旧写真を撤去。横断通路を専用のpassage室とし、R10のトンネル側道名は外部の観測路に残す。

共有モデルの幅はx=15.7..17.3、床z=-3、天井z=-.65。線路中心y=1/5はこの地下区間の上を横切る。南階段は18段・各1/6m、y=-8.4から-3.9へ下降。荷物室の東戸は地上の上部踊り場につながる。階段室の北端は駅舎壁の外へ2.1m延びる覆われた階段部分で、床が下がった後に南ホームの下へ入る。平らな横断通路はy=-3.9..6.1の10m。

北の15段・各.15mはy=6.1..9.475でz=-3から-.75へ上がる。北の踊り場はy=9.475..10.875。ここで視線が地上z=.9へ戻り、窓の下端z=.1から外の線路を観察する。最後の5段で地上へ出る。地下床z=-3の水平通路には窓を置かない。

ゲーム内は地上の南階段→地下通路北向き→北の踊り場→北ホームの順。北からは踊り場→通路南向き→南階段→荷物室と戻る。視点矢印で離れた場所へ切り替えず、写真に写る通路や階段を選んで移動する。北出口の開閉はその踊り場で操作し、通路途中からホームへ直接移れない。

写真は投影図を参照してbuilt-in image_genで三枚制作。原画像のUUIDはentry=d723f684-42d9-4af6-a752-32c060159d7e、north=5764d308-eb2e-435e-b605-c54821c734b8、south=e739f5e3-c54e-40f8-904a-a8819863fcfb。旧北踊り場の開閉・窓写真は上がった観測地点として継続利用。短い南階段へ直接戻る旧return写真は採用から外す。採用136点、原画像と生成指示はdocs/remake/assets.json/prompts参照。

既存の地下保存はtunnel:0→passage:2、tunnel:1→passage:3へ移し、戸・可動棚の現在状態を維持。passageRevisionで新しい側道保存と区別する。84テスト、ビルド、採用画像の参照監査に合格。1440px PCと390pxタッチで通常の荷物室から北ホームまで往復し、通路途中の再読込、観測窓の接写、タップ領域を確認。モバイルで戻るボタンが奥の階段を覆っていた問題は、ボタンを画面下へ移して修正。

投影図は寸法の拘束を確認するためのもの。生成写真のレンズと壁の厳密な投影差、北踊り場・外側の入口の対応、窓から見える広域路線との位置関係はG1の最終目視へ残す。この修正だけでQ25やG1/G2/G3全体を合格としない。次の実装はQ27の現物レバーと、その位置に連動するレール。
