# 停車灯の保持ピンの確認（2026-10-01）

Q22の釣り合い箱から、二枚の羽根の覆いと保持ピンを別々に回収できる。ピンは右端の上下二つの耳金へ差し、羽根がガイドから抜けるのを止める部品として描く。取り付けは覆いとピンの両方を持っているときの一工程。取り外しで両方が持ち物へ戻る。追加の独立問題には数えない。

State.locations.retainingPinはbalanceChest／inventory／signal。箱の開閉と所在によって取得を判定し、汎用take／putによる設置の迂回は通さない。信号の光路、列車の停止と乗車、進入中の目標描画はsignalReady（覆いとピンがともにsignal）で再評価する。装置の羽根の位置は取外し後にも残り、再設置して操作できる。

retainingPinRevision=1の保存データでは覆いとピンの設置状態の不一致を拒否。以前の保存で覆いが既に設置されていれば、ピンもsignalへ移行する。未設置なら箱に追加する。旧試作の信号構造全体を移行する経路では覆いとピンの両方を持ち物へ戻す。既存の進行を奪わず、次回保存から現仕様で扱う。

PCの箱と停車灯、390×844のタッチ環境の箱の拡大・ピン取得・取付け・羽根の拡大を目視した。PCで二枚の羽根を[2,3]へ動かし、二つの現物光路が開くことを確認。覆いとピンを取り外し、再設置し、再読込して所在が保存されることを確認。スマートフォンに画面全体の横はみ出しはない。
