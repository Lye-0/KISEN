# Q25／Q27 線路配置の中間検証

## 確定したこと

- `src/remake/routeGeometry.ts` は `model.ts` の全ての接続を同じメートル座標へ置く。意図しない平面交差はなく、投影が重なるのは旧線 C–X と通過線 E–F の一箇所だけ。
- 交差の真下はおよそ `(-46.923, 30)`。C–X の高さは約 4.15 m、E–F は 0 m。旧線の終端 X は 4.5 m の盛土上。C から X までの勾配は約 3.39%。跨線橋の観測位置 `(-8,25)` から交差まで約 39 m で、現物が読める距離にした。
- 途中案は交差が4箇所になったため破棄。以前の交差1箇所案は交差が駅から百メートル近く離れ、夜の写真では読みにくいため破棄。`route-network.png` は採用案の**制作者用**俯瞰図であり、ゲーム内の解答図ではない。
- 橋からの採用写真 `bridge/east-tag.webp` と、札を取った後の `bridge/east-tag-empty.webp` に旧線の橋脚と、その下を続く地上線を同じ画角で追加。どちらも写真全体を生成し、細い高架だけの解像度の違う貼り重ねを避けた。手すりの現物操作は接写写真で状態を示す。
- 390px画面の全景では高架が小さかった。交差をタップすると元写真の800×620px範囲を最大800px幅で見る。PCで元画素と同倍率、スマートフォンでは縮小のままなので、無理な拡大による粗さを避けた。PC・390pxで目視。

## 未合格・次の制作条件

- Q25 が成立するには、橋だけでなく地下の窓と北ホームから**同じ二本の線**を読めることが必要。窓・ホームの候補写真はあるが、駅舎と線路の向き、線路の本数が橋の写真と完全に合っているか再検査するまで採用しない。
- 実画面では高架の高さが読めても、E–F が屋根の下で連続すること、C の先が F に繋がらず X へ行くことはまだ確証に足りない。地図を出して正解へ誘導せず、別観測点で同じ橋脚・枕木・標柱を照合できる絵を優先する。
- 俯瞰図の駅周辺は横幅の狭い分岐群を制作者用に直線で示す。ゲーム画像へ移すときは線路の曲率と分岐器の実寸を確認する。R–F は北側の迂回線。G1は**未合格**のまま。
- Q27 は6個の可動レバー、鎖錠、実レールの状態差分、現在の B–D 閉塞と二つの許容帰路が未接続。`routeGeometry.test.ts` が通っただけで完成と判断しない。
