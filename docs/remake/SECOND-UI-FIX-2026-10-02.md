# 独立レビュー後の第2次UI修正

2026年10月2日。KISEN/remake。独立部分試遊で残った問題を、進行への影響が大きい順に対応した。

## 対応

|対象|変更|維持した推論・条件|
|---|---|---|
|時計|写真に残る旧数字へ別座標の針を重ねる方式をやめ、文字盤・数字・60目盛・針を同じ投影で描く。針先を分目盛へ延ばす。「同時撮影」を明記|23:17/23:12、補正と受取順。針の時刻の数字表示は追加しない|
|操作欄の重なり|上下UIに使う高さを共通で確保。掲示・帰りの車内の操作を本文の流れへ配置。旧余白の二重確保も除去。結果表示を操作帯から移動|操作の条件・道具の所在|
|券の照合|写真の選択列と券の同じ列を強調。各控の表裏を表示。資料と操作帯を別領域にし、略図との往復で読み位置を保存|全実例・孔・通過側・列順・鋏・便の推論。正しい券の自動生成なし|
|柵|解除後の状態を表示。寄り画面で柵を押して開ける。横棒への再入力で意図せず留めを戻さず、戻す操作を分離|支え・薄片・解除の前提はそのまま|
|ベル|切替からの共通配線を連続させ、刻印の拡大参照と紙送りを追加|正しい接点・打数・間隔は示さない。応答・給電・停車判定は同じ|
|遮光器|外した覆いに羽根が属する説明と空の取付枠の表示。未装着の羽根拡大操作を無効化|羽根・覆い・保持ピン・光路・成立位置|
|モバイル全景|全景に加えて大きい表示と横移動を選べる|景色・配置・発見条件|
|記録|種類を示す折り畳み一覧へ変更。時計等の不要な内側の縦スクロールをなくす|記録値・写し・正解未判定の性質|
|断片選択|片の輪郭と選択欄を強調。操作列の高さを常に確保し、選択で盤面を移動させない|裂け目・回転・裏面・接合|
|座席|全景の遠い座席から前方へ寄れる。二枚扉の対象名、背の反転と空ポケットの反応を追加|座席番号の答えや発見条件は示さない|
|鞄|帯・留め・口それぞれの物理反応を表示|帯と留めを外す前提|
|試し切り|紙縁を押す入力と孔の比較を示す。同じ見た目の控を試し紙からも参照可能にする|孔の形・鋏の違い・切孔の和集合|
|灯具方向|微小な方向変更を指標と結果文で示す|照射角・光学判定|
|踏み板|適度な表示拡大で接写の大きさを確保|写真と取付列・足場の幾何|
 
ユーザー指定により、封筒の大きさ・ぼけは変更しない。TrainのNearSeatLayersの内容が修正直前と同一であることを編集時に照合した。画像素材は変更していない。

## 最終確認結果

- 最終版の型検査・本番ビルド成功。既存39ファイル136テスト全件成功。素材監査成功（旧版70、新版197、132.7 MiB）。
- 過去の通常保存を読み込み、停車済み列車から乗車→車内の時間経過→降車→帰線の終幕へ到達。判定条件を変更せず既存保存からの進行が成立することを確認。
- 確認した画面の実行時エラーなし。掲示と車内のボタンは通常クリック、モバイルの資料操作は実タップ。強制クリック・ハンドラー直接実行・ゲーム状態のJavaScript注入は使用しない。
- UI Evolveの代表性のある確認へ、アナログ計器の数字・目盛・針先を共通の投影で逆読みする確認を追加。構造検証PASS。修正後の独立した初見試遊は未実施。
