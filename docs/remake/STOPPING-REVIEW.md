# Q28–30 停車の代表試作

KISEN/remake。通常導線では未到達の独立検査入口 `?remake=stopping`。作者が位置と便を知って行った操作検査であり、初見評価ではない。

## 実装と検証

- `signal/footing` の正解フラグを判定から除去。実在する二つの灯具の所在と取付位置、二枚の羽根、固定光路、現在経路、扉幅と間隔で評価する。覆いと灯具は取り外せる。
- 第2便の扉が二枚の踏み板へ収まる位置は7/11m。灯具の個体を逆に置く同値解も受理。全6便×異なる2穴の56配置、羽根25配置を走査。第5便の6m間隔は停車できても両扉を支持できない。
- 進入4秒、通過/退去3秒。進入と退去は閉扉写真、停車は同一車両の開扉写真。到着時の扉中心を固定し、後から灯具を動かしても列車は移動しない。使用中の分岐は固定し、未使用枝だけ操作可能。乗車時に足場、光、経路、設置券、押さえを再評価。
- 保存再開は進入/退去の途中値を含む。新状態の不整合は拒否。以前のversion2試作は券や持ち物を保持し、仮の停車だけを未到着へ戻す。初回version1は引き続き混ぜない。
- PC1440×900: 灯具7/11、羽根2/3、便2→停車。6/10へ移動→誤停車→乗車を拒否。灯具だけを7/11へ戻しても車両は6mのまま。送り出し→呼出→7m停止→再読込で保持を確認。最後の検査区間にpageerrorなし、横はみ出しなし。
- タッチ390×844: 同じ保存を読み込んで再開。羽根のドラッグがpointercancelで止まる不具合を、操作SVG上のtouch-action指定で修正。CDPの指操作で手前羽根3→1、再読込後も[2,1]。踏み板接写が小さかったため一枚ずつ切り替える形へ変更。操作枠とキーボード入力を維持。
- 65テスト、型検査、ビルド成功。これは全編の品質や初見難度の合格を意味しない。

車両画像は基準となる二扉中心486/1465px、敷居600pxを現場の4m間隔へ対応させる。6m間隔では中央の車体帯を広げ、扉自体の幅を変えない。画像と物理寸法の最終採点、拡大時の解像感にはなお改善余地がある。前景と踏み板は同じ背景の遮蔽で車輪を隠し、灯具は同じソケット位置へ描く。
