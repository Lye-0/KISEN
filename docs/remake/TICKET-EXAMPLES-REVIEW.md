# Q20 乗車券控の代表実装

駅務室の鋏と用紙から切符の作業面へ進み、左端の乗車券控を開く。甲乙丙丁の切符は、同じ二口接続の過去の経路から生成する。写真を解説文へ置き換えず、切欠きとII/III列の部分写、各地点の二枚の連続写真を比較できる。全体の券と経路は表示しないため、帰路の完成見本を与えない。

|控え|表示する二列|対応する局所写真|
|---|---|---|
|甲・東側着|B白、E黒|給水槽と分岐橋|
|乙・西側着|E白、B黒|分岐橋と給水槽|
|丙・白沢行|B白、D白|給水槽と鉄塔、過去の通行|
|丁・白沢行|C黒、E白|保守小屋と分岐橋|

作者用の全履歴はjourneyExamples.tsに保持する。通常画面はobserved=[1,2]を使い、紙の二列と端だけを同じ倍率で投影する。裏返したときは切欠き、列、孔も同じ個体として反転。自分の試し切りは既存の切符作業面と切った券の閲覧で比較できる。履歴が空なら閲覧ボタンは表示しない。

写真用の局所モデルは前後12mの移動を固定焦点・固定方向で投影する。白標柱は一刻み、黒標柱は二刻み。各組の後半では先に通った標柱が画外へ去り、反対側の標柱が残る。Dの鉄塔はK1と共通の四本の平行支柱・X材・西の錆色梯子、二本の木製電柱を使う。電柱の高い白い塗装傷と低い角形標柱の刻みは別物。十二枚の写真を採用し、画面内最大600px・拡大2.7倍で元画像1672px以内に収める。

PC1440pxとタッチ390pxで四資料、写真切替、表裏、並置、中心拡大、記録、再読込を検査。通常の荷物室→駅務室→鋏と用紙→作業面→乗車券控の入口と戻りを確認。実際に自分の券を切った後、切った券の比較へ進めることも確認。記録欄はテーマに沿ったスクロールバーと固定ヘッダーを使い、スクロール後も閉じるボタンを操作できる。81テスト、ビルド、134採用素材の監査に合格。

検証専用入口は ?remake=journeys、保存グループkisen-remake-v2:journeys。通常進行とは分ける。画像制作はbuilt-in image_gen。最終採用IDと原画像はdocs/remake/assets.json、検証画像はverification/2026-09-30-ticket-examples/。正確な生成指示はdocs/remake/promptsへ記録する。

局所投影の検査は全路線の位置・各写真の整合を証明しない。K1の観測位置と路線全体の関係、地下横断通路、Q25、Q27は未検証。G1/G2/G3全体は未合格。次はz=-3の長い横断通路と、線路高さへ戻る北側踊り場を実装して空間を照合する。
