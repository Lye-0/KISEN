# 帰線 再計画 v2

2026-09-29。現在の設計入口。作品名は **きさらぎ駅 ― 帰線（きせん）―**、識別名・実装先はKISEN。

雨の駅を歩き、残された旅の記録を読み、帰るための列車を迎える。写真の中の物を手で扱い、離れた場所で得た理解が一つの帰路へまとまる長編脱出ゲームを作る。

## この版の位置付け

作品として作る方向と、論理試作に渡す仕様を決めた計画。最終画像・実装・初見試遊の合格はこれから確認する。候補の分類と時間配分は制作上の仮説である。

六問の論理・視覚根拠、探索の一巡、終盤の加工と設置を先に試作する。進行判定、描画、現物の操作、根拠を別々に審査し、結果を[05](05_PRODUCTION.md)の表へ残す。

`MODEL_CHECKS.json` は小さな有限モデルの机上確認。写実性、謎の公平さ、楽しさ、所要時間の検証ではない。
