# きさらぎ駅 ― 帰線 ―

## 体験

列車が停まった。窓の外には、覚えのない駅名がある。

雨のホームには誰もいない。改札の先を歩くと、さっきの傘の前へ戻ってくる。車内に残された写真、受け取られなかった荷物、途中で切られた乗車券を調べるうち、誰かもここから帰ろうとしていたと分かる。

あなたは駅を歩き、写真の物を手に取り、過ぎた出来事と現在の線路を結び直す。やがて暗かった向こう側のホームに灯が入り、列車の窓に朝が映る。自分で整えた帰路と手元の切符を確かめ、扉を開けて帰る。

## プレイヤーが行うこと

見回す、近づく、裏返す、並べる、引く、照らす、録音を聞き返す、取り付ける、紙を切る。操作は同じ現物の中で続く。観察から得た仮説を自分で試し、予測した変化が駅の空間に残る。

手掛かりは、摩耗、雨の跡、遮蔽、物の裏面、開閉、短い印字、音と動き。資料の文章は記入欄・時刻・短い注意書きとして存在する。共通UIは記録、持ち物、地図、設定、任意ヒントを支える。

## 五章の進行

|章|目の前の目的|主な発見|章の終わりに残る変化|推理・探索の時間予算|
|---|---|---|---|---|
|I 雨の終点|車内とホームを調べ、帰れる手掛かりを得る|写真に写る塔と標柱が、到着方向を語る|駅務室へ入り、同じ駅へ戻った旅程を持つ|45〜60分|
|II 残された夜|記録と忘れ物から、ここで起きた順番を調べる|二本の録音は開始位置が違う|保管物と跨線橋へアクセスし、帰る便の条件が分かる|60〜80分|
|III 六つ目の窓|外観と室内を照合し、見えていなかった場所へ進む|建物の一間と、その先で見える線路が地図を変える|地下の通路から北ホームへ到達。券の規則を学ぶ|80〜100分|
|IV 帰る線|地形、現在の運行、光と反射を照合して帰路を作る|平面で交わる線がつながるとは限らない|実際の分岐と停車位置が変わり、向こうの線路に灯が続く|95〜125分|
|V 朝の乗車券|現在の帰路を、自分が使える切符へ変換する|同じ地点でも、通る側で残す印が違う|切符が受け部を通り、車両が止まり、乗って帰還する|80〜115分|

合計は360〜480分の制作予算。試遊結果ではない。操作迷い、機械的な往復、待ち時間をこの予算へ含めない。中盤までの測定で内容量を見直す。

## 探索のリズム

序盤は一つの目前の目的から始める。駅務室が開いた後は「記録と忘れ物」「外壁と跨線橋」の二系統を並行して調べられる。北ホームの発見後は、券と線路の二系統が合流する。各区間には短い物理パズル、観察による中規模の発見、成果を受け取る場面を置く。

主要な発見は、同じ物を別の条件で使う場面へ続く。例えば手元の灯具は、暗い場所を照らし、ガラスの映り込みを調べ、最後には停車位置を示す器具へ取り付ける。所持している物と、その場所に置いた物は現物として見分けられる。

## 世界の規則

駅の外へ出る道は同じホームへ戻る。置いた傘、ベンチの欠け、雨の跡で同じ場所だと確かめられる。

この駅の券には、通った地点と通った側が孔として残る。途中で降りた旅と、これから帰る旅を、現場の通行例と残された券から学べる。券の形と駅の受け部は同じ規則で働く。

建物、道具、光、紙、車両の位置は一貫した空間に存在する。間違えた試行からは、触った物を戻し、観察をやり直せる。誤った便に乗った場合は、短い帰着で駅へ戻り、手元の記録と道具を保つ。

## 怖さと物語

誰かが作業を中断した場所に見えることを重視する。鞄の補修、紙に残った違う押し跡、濡れていない傘の内側、録音だけにある足音などが、調査の根拠と気配を兼ねる。

中盤、プレイヤーが鳴らしたベルに、録音とは違う間隔で遠くの応答灯が返る。北ホームへ初めて降りると、南側で見ていた同じ窓が暗い。終盤、動かした分岐の先を灯が通り、列車が実際にその方向から入る。

帰還先は「白沢」。冒頭から携帯にある駅の写真と、窓の外の構造・朝の動きが対応する。降車は成果を確かめる終幕として置く。最後の切符の裏には、もう一つの改札痕が残る。

## 記録と再開

写真、録音、手元の券、描き込んだ地図を、観察した状態で保存する。地図には訪問した位置と現在通れる接続が残る。再開時は最後に触った現物と短い観察メモから戻れる。複数日に分けたプレイを想定する。

## 現段階で確定していること

題材、作品のテイスト、五章の目的、核心の役割、主要な空間、共通操作を再計画の基準にする。具体的なカメラ投影、可動物の連続動作、手掛かりの最終可読性、初見時間は試作で確かめる。
