# 変更理由・監査対応 — 開発者用

2026-09-29。ここは比較・原因分析のための例外面。作品の紹介、台詞、通常UI、画像生成briefは02〜04の現在仕様から作る。

## 再計画の変更判断

維持するのは、きさらぎ駅、写実、少ない言葉、静かな不気味さ、深い連鎖と短問、長編という依頼。六つの核心の題材は再利用するが、元計画09〜13をそのまま実装し直す扱いにはしない。

- 視点と機構：通常30視点と対象の状態契約を設計。問題ごとの共通画面を主な操作面にする構造は採用しない。
- 空間推理：正解セルを塗る課題から、同じ柱間の対応と実際の階段戸へ変更。見つけた位置から線路を観察できることを成果に追加。
- 券：全体の行き／帰りで一段を選ぶ規則から、各地点の通過側へ変更。同じ地点でも現在の経路によって段が変わる。
- 経路：二つの合理的な経路を受け入れ、過去の到着順、現在の閉塞、立体交差、通過側に別の用途を与える。
- 音：録音の同期を実際の音・機器の動き・等価な視覚記録で扱う。現在の応答は本人が作るベルの間隔で試す。
- 終幕：降車の確認は締めくくりとして扱い、独立した中問の数へ加えない。
- 規模：38項目の継続を前提にせず、32候補から再構成。単純な鋏の選別は短問へ分類する。時間目標は制作上の仮説として保持し、減った判断を実測と台帳で補う。

## 現段階の自己審査

強い部分：終盤の二経路と、同じ地点の段が変わる券の設計。隠れた空間の発見から線路を読み直す用途。解いた物・得た知識・現在の成立を分けた計画。

危険な部分：Q03/Q06の時系列と視差が写真で読めるか。Q15の外形が視点を変えても揃うか。Q23の応答が単なる三択へ縮まないか。Q27が少数試行で十分にならないか。Q29の足場計算が自然な観察として成立するか。17の中規模候補の実時間と難度。

これらは計画を不問にする注記ではなく、G1〜G3で採否を決める対象。結果が不合格なら台帳・空間・章の量を更新してから展開する。

## pink-elephant-guardの適用

TARGET_STATE：きさらぎ駅で、写実の現物を探索し、複数の理解から帰路を作る長編。

REJECTED_HISTORY：監査14と上記の不採用の実装方式・完成判定。個々の題材、短問、暗証、図版全般を禁止したものではない。

VISIBLE_EXCEPTIONS：この変更記録、監査、検査の停止条件。問題を隠さず説明するために必要。

SURFACE：02の作品本文、今後の台詞・UI・画像プロンプト。これらは現在の目的・物・光・操作・結果から記述する。除外案の語句や削除理由を作品の主題にしない。画像・音声は未制作のため、画素・音の残留を検査済みとはしない。

creative-ui-design/ui-evolveの既存知見には、現物の同一性、補助UI、代表確認の限界が既にある。今回もそれを適用する。新しい実画面による効果の証拠はまだないため、同じ原則を汎用スキルへ重複追記しない。

## G1での接続モデル修正（2026-09-29）

実装前の表は、分岐へどの方向から入っても同じ行先へ進む有向グラフだった。実物のレールの接続と一致しないため、選択した二口の間だけを通すモデルへ変更した。Eは三口から二口を選ぶ三位置、ほかは二位置。96配置を列挙し、二つの帰路・未使用分岐を含む4配置と、逆側からの到着経路R–F–E–B–A–Sを確認した。

この変更に伴い、Q06のケースは通過した四地点、Q21の過去券はB–D、Q26は自分の到着旅程ではなく過去の券との現在比較へ更新。Cの旧線はFへつながるように見えるが実際はX終端という現物にする。端子設定を増やして難易度を達成したという判断ではない。可動レールの幾何、情報の読解、通常試行の省略検査は引き続きG1/G3で行う。

## G1での写真順序の具体化

車両と遮断機の断片だけでは、各写真の前後が画面から一意になる仕様が未確定だった。四枚の写真カードの裏にある同じ券の部分写しを、位置ごとの情報として比較する方式へ具体化した。個数は0/1/1/1。写されていない欄は不明として扱い、24順列中一つだけが印の増加と一致することを確認した。

券を後半へ再使用する一方、券の形をケースへ転記して空間推理を省略できる接続は採用しない。ケースは「撮影した側」の四つの輪とし、写真順と方位入り略図・柱の前後を合わせて西/東/西/北を判断する。まだ写真カードの裏面とケース実物は未制作で、G1全体合格ではない。
